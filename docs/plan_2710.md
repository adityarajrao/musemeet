## S4 — Core Architectural Safeguards

1. **Anti-Sycophancy Engine:** Agents are prompted as skeptical talent scouts with an explicit Opportunity Cost Budget (1 date/week). Default prior is rejection unless genuine multi-dimensional chemistry is verified.
2. **Two-Tier Privacy Isolation:** Raw browsing data, private notes, and raw photos NEVER leave the user's local sovereign vault. The digital lounge receives strictly abstracted, sanitized cards.
3. **The Human-Agency Non-Interference Guarantee (Zero Date Scripting):**  
   * **Why We Reject "Date Pre-Mortems":** An AI should never coach, script, or micromanage how two humans talk on a date. Over-coaching creates performance anxiety and destroys organic connection.
   * **The Policy:** Agents verify compatibility, attachment stability, and dealbreaker boundaries in the background. Once an introduction is made, the platform provides mutual curiosities and a venue setting, then **steps back completely**. Spontaneous chemistry must remain sovereign.
4. **Grounded Spatial Venues:** Dates are anchored to verified physical venues from `data/venues.json` with measured decibel levels ($<50\text{ dB}$) rather than hallucinated AI recommendations.
5. **Neutral Lounge Moderator:** A silent 3rd-party observer scores LSM and Gottman bids, eliminating self-serving bilateral negotiation bias.
6. **Theatrical Turn Budgeting:** Capped at 14–18 turns total (~60–90 seconds streaming replay) to keep presentation pacing crisp.

### Task 1: AirGap Egress Security Guardrail (`egress_guard.js`)
* **Priority:** HIGH (Demonstrates defensive security depth) | **Estimated Time:** 1.5 hours
* **Target File:** `musemeet/agent_engine/vault/egress_guard.js`
* **Input:** `turnDialogue: string`, `options?: object`
* **Output:** `sanitizedDialogue: string` (or throws `SecurityViolation` if critical PII is detected)
* **Specification:**
  1. Detect and intercept Regex PII patterns:
     * Email addresses: `\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}\b`
     * Phone numbers: `\b(?:\+?\d{1,3}[- ]?)?\(?\d{3}\)?[- ]?\d{3}[- ]?\d{4}\b`
     * Exact street addresses: `\b\d{1,5}\s+(?:[A-Za-z0-9.]+\s+){1,4}(?:Street|St|Avenue|Ave|Road|Rd|Boulevard|Blvd|Way|Drive|Dr)\b`
     * Raw clock timestamps: `\b\d{1,2}:\d{2}\s*(?:AM|PM)\b`
     * Raw web URLs: `https?:\/\/[^\s]+`
  2. If pattern matches:
     * Redact or sanitize to `[PROTECTED_VAULT_METADATA]`
     * Log a security interception event
  3. Create automated unit test: `musemeet/tests/test_egress_guard.js` testing standard text, email injection, phone injection, and address injection.
