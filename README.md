## 💡 Overview

Dating apps have devolved into superficial, time-consuming swiping loops where humans suffer from extreme burnout and the "self-reporting paradox"—struggling to articulate what they truly value in a partner.

**MuseMeet** replaces manual swiping with autonomous, agent-mediated matchmaking:
1. **Sovereign Persona Distillation:** With explicit user opt-in, a personal Muse agent observes authentic intellectual interests, communication rhythms, and habits on a rolling basis.
2. **Zero-Knowledge Privacy:** Raw browsing telemetry and private data never leave the user's sovereign agent vault.
3. **Agent-to-Agent Rendezvous:** When seeking connection, two personal Muse agents meet in an autonomous digital lounge, conducting a multi-turn chemistry check (wit, intellectual synergy, lifestyle friction, core dealbreakers).
4. **Curated Introductions & Date Planning:** When mutual chemistry is verified, agents introduce the humans with an explainable compatibility dossier and a bespoke first-date itinerary with visual moodboards generated via **Muse Image**.

---

## 🛠️ Architecture & Tech Stack

* **Persona & Reasoning Engine:** Meta Muse Spark (1M token context, multi-turn reasoning) via Meta Model API
* **Agent Negotiation Protocol:** Structured multi-turn agent tool loops & Connectors
* **Multimodal Generation:** Meta Muse Image & SAM 3.1 for custom date scene generation
* **Frontend:** Interactive Next.js / Vite web experience showcasing live agent dialogue & compatibility analytics

## 🚀 Quickstart

### Prerequisites
* Node.js >= 20.x or Python >= 3.10
* Meta Model API Key

### Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/adityarajrao/musemeet.git
   cd musemeet
   ```
2. Copy environment template:
   ```bash
   cp .env.example .env
   ```
3. Install dependencies and start development server (details to follow).
